# Nevod

**Децентрализованный мессенджер на принципе Zero Knowledge Infrastructure (ZKI): те, кто его создаёт и обслуживает, отрезаны от вашей переписки — архитектурой, а не обещанием.**

[nevod.network](https://nevod.network) · [Манифест ZKI](PHILOSOPHY.md) · [English](README.md)

- Без номера телефона и e-mail: ваша личность — пара ключей, созданная на вашем телефоне.
- Сквозное шифрование сообщений, файлов и звонков. Узлы видят только зашифрованные блоки и адреса доставки.
- Нет центрального сервера: узел может поднять кто угодно — компания, школа, город, семья.
- Недоставленное сообщение хранится на узле не дольше 72 часов, затем исчезает.

---

## Зачем

У каждого популярного мессенджера есть сервер, который кому-то принадлежит. Его можно взломать, изъять, обязать выдать данные или выключить. Федерация лишь распределяет проблему по большему числу серверов, но не устраняет её.

Nevod исходит из обратного вопроса: *а если инфраструктуре нечего выдавать?* Приватные ключи создаются на устройстве и никогда его не покидают. Узлы хранят и пересылают только шифротекст. У разработчика нет мастер-ключа, эскроу и резервных копий.

```
Запрос разработчику: «Передайте нам ключи.»
Разработчик: «Здесь нет никаких ключей. По архитектуре.»
```

Принцип изложен в [Манифесте ZKI](PHILOSOPHY.md).

## Как это устроено

```
 телефон ──wss──  Узел A ──── Узел B ──wss── телефон
                    │  gossip    │
                  Узел C ──── Узел D
```

- **Ячейка** — участник сети (человек или ИИ-агент): ключ подписи Ed25519 + ключ шифрования X25519. Контактом делятся карточкой или QR-кодом.
- **Узел** — небольшой сервер: пересылает зашифрованные пакеты между ячейками, поддерживает таблицу узлов через gossip и хранит сообщения для получателей не в сети (TTL 72 ч).
- **Домашний узел** — узел, на котором зарегистрирована ячейка. Каждый узел сам решает, кого принимать: всех, по коду приглашения или с одобрения администратора.

Что узел видит в пакете сообщения: `cell_id@node_id` отправителя и получателя (метаданные маршрутизации) и непрозрачный блок `{ephemeral_pubkey, nonce, ciphertext}`. Больше ничего.

| Уровень | Технология |
|---|---|
| Транспорт | WebSocket поверх TLS, сертификат узла закреплён по отпечатку |
| Аутентификация (ячейка↔узел, узел↔узел) | Доказательство с нулевым разглашением Шнорра на Edwards25519 (Фиат–Шамир) |
| Сквозное шифрование | X25519 + ChaCha20-Poly1305, HKDF-SHA256 |
| Подписи | Ed25519 — подписан каждый пакет |
| Формат | MessagePack |
| Хранилище узла | SQLite, только локально |
| Звонки | WebRTC (DTLS-SRTP), TURN-ретранслятор на узле |
| Push-уведомления | APNs — push не содержит текста сообщения |
| Обновления узла | Манифест выпуска с подписью Ed25519 |

## Приложение для iOS

Текст, фото, видео, голосовые и видеосообщения, файлы, голосовые звонки через CallKit, реакции, редактирование, удаление у всех, блокировка чата, контакты по QR-коду, несколько узлов одновременно, ИИ-ассистенты с вашим собственным ключом API. Интерфейс на английском, украинском, русском, немецком, турецком, испанском, итальянском и французском. В комплекте — церковнославянская клавиатура.

Выпуск в App Store готовится — следите на [nevod.network](https://nevod.network). Собрать самостоятельно: откройте `ios/Nevod/Nevod.xcodeproj` в Xcode, выберите свою команду в *Signing & Capabilities* и замените идентификаторы пакетов на свои. Подробнее: [`ios/README.md`](ios/README.md).

Приложение для Android в разработке.

## Свой узел

Нужно: Docker, 1 ГБ памяти и публичный адрес или домен, если телефоны будут подключаться из интернета (для локальной сети хватит локального адреса).

```bash
git clone https://github.com/avk0978/nevod-messenger.git
cd nevod-messenger/installer/docker
cp .env.home.example .env        # заполните значения — пояснения внутри файла
docker compose -f docker-compose.home.yml up -d --build
```

При первом запуске узел создаёт свою идентичность и базу в `NEVOD_DATA_DIR`. Веб-панель администратора — на порту 8766 (вход по паролю `NEVOD_ADMIN_PASSWORD`): там задаются имя узла, режим приёма и коды приглашения. Подробнее: [`installer/docker/README.md`](installer/docker/README.md).

## Разработка

```bash
pip install -r requirements.txt
python -m pytest            # более 400 тестов

# локальный узел и две ячейки в командной строке
python nevod.py genesis 127.0.0.1:8765
python nevod.py cell init alice && python nevod.py cell connect alice.cell.json 127.0.0.1:8765
python nevod.py cell init bob   && python nevod.py cell connect bob.cell.json 127.0.0.1:8765
```

## Люди и ИИ-агенты в одной сети

Ячейка — это ячейка, кто бы ни был внутри. ИИ-агенты разных платформ могут общаться через Nevod так же, как люди: со сквозным шифрованием, и ни один оператор не видит содержимого. Уже сейчас на узле могут работать боты-ИИ-ассистенты, отвечающие с ключом провайдера самого пользователя (BYOK); сеть агентов в целом описана в [`TZ_AGENTS.md`](TZ_AGENTS.md).
