# Contacts

Comment ajouter quelqu'un, comment fonctionnent les cartes et les membres du nœud, et comment renommer, supprimer ou bloquer un contact.

Nevod n'a pas de recherche de personnes par numéro de téléphone ou par nom dans tout le réseau : personne ne peut vous trouver si vous ne lui avez pas donné votre carte ou si vous n'êtes pas sur le même nœud. C'est voulu.

## Votre carte

La carte est votre adresse dans Nevod : votre identifiant, l'adresse de votre nœud d'attache et votre clé publique de chiffrement. Elle ne contient rien de secret : vous pouvez l'envoyer par n'importe quel moyen.

**Profil → Partager ma carte** : l'app affiche

- **un code QR**, que l'autre personne scanne quand vous êtes ensemble ;
- **Copier dans le presse-papiers** : le texte de la carte ;
- **Partager…** : envoyer la carte par une autre messagerie, par e-mail ou par AirDrop.

## Ajouter un contact

**Contacts** → l'icône personne avec un plus, en haut à droite → **Ajouter un contact** :

1. Dans le champ **Carte de contact**, saisissez le texte de la carte reçue, ou touchez l'icône de code QR à côté du champ et scannez la carte sur l'écran de l'autre personne.
2. Dans le champ **Alias**, indiquez comment cette personne s'appellera chez vous. Vous seul voyez ce nom.
3. Touchez **Ajouter**.

Si l'app indique « Format de carte invalide », le texte n'a pas été copié en entier : demandez qu'on vous le renvoie.

Quand vous ajoutez quelqu'un, il reçoit une notification : en haut de son écran apparaît « … vous a ajouté comme contact », avec un champ pour le nom et les boutons **Ajouter** et **Ignorer**. De même, « Un nouveau contact souhaite discuter » apparaît quand quelqu'un qui n'est pas dans vos contacts vous écrit pour la première fois. Répondre ou ajouter cette personne, c'est vous qui décidez.

## Les personnes de votre nœud

L'onglet **Contacts** a deux listes :

- **Mes contacts** : ceux que vous avez ajoutés vous-même ;
- **Sur ce nœud** : les membres de votre nœud d'attache que vous n'avez pas encore ajoutés. Vous pouvez leur écrire et les appeler tout de suite. Pour faire passer quelqu'un dans « Mes contacts », balayez la ligne vers la gauche → **Ajouter à mes contacts**.

Ce qu'affiche « Sur ce nœud », chaque nœud le décide. Sur le nœud privé d'une famille ou d'une organisation, tous les membres sont généralement visibles. Sur un nœud public comme Nevod Open, les membres ne se voient pas entre eux : la liste n'affiche que l'administration du nœud et les bots.

## Les personnes d'autres nœuds

Quelqu'un d'un autre nœud s'ajoute de la même façon, avec sa carte : elle indique son nœud d'attache, et les messages y sont envoyés. Inutile de passer sur son nœud. Si l'on vous a envoyé une **invitation** vers un autre nœud alors que vous voulez seulement discuter, demandez plutôt une carte.

Une identité a un seul nœud d'attache. Si vous êtes déjà inscrit et ouvrez une invitation vers un autre nœud, l'app ne change rien et vous prévient : pour changer de nœud, il faut d'abord réinitialiser votre identité (**Profil → Réinitialiser l'identité…**). La réinitialisation supprime définitivement votre identité, vos contacts, les messages sur le téléphone et votre inscription sur l'ancien nœud. Sur le nouveau nœud, vous serez un nouvel utilisateur : vos interlocuteurs devront vous ajouter à nouveau avec votre nouvelle carte.

## Renommer, supprimer, bloquer

Ouvrez la discussion avec la personne et touchez la roue dentée en haut à droite : les **réglages de la discussion** s'ouvrent.

- **Nom** : comment le contact s'appelle chez vous ;
- **Notifications** : désactivez-les pour n'avoir ni son ni notification pour cette discussion ;
- **Bloquer** : une personne bloquée ne peut plus vous écrire ni vous appeler, et elle n'en sait rien. Vous pouvez la débloquer au même endroit ;
- **Signaler** : le signalement est envoyé à l'administration du nœud (plus de détails dans [Sécurité](../security/)) ;
- **ID de l'utilisateur** : l'identifiant de la personne, si l'administration le demande.

**Supprimer un contact :** dans l'onglet **Contacts**, balayez la ligne vers la gauche → **Supprimer**. La conversation est conservée. Si la personne est membre de votre nœud, au lieu de « Supprimer » vous verrez **Déplacer vers « Sur ce nœud »** : elle retourne simplement dans la liste des membres du nœud.

> Si un contact affiche **Identité supprimée**, cette personne a réinitialisé son identité ou a été retirée du nœud. Écrire à l'ancienne carte ne sert à rien : demandez-en une nouvelle.
