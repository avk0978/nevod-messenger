# Messages and files

How to write, send photos, videos, voice messages and files, what the icons next to a message mean, and what you can do with a message you've already sent.

Everything you send is encrypted on your phone with the recipient's key. Nodes deliver messages but can't read them.

## Text

Type your message in the **Message** field at the bottom of the chat and tap the blue arrow. Links in messages are tappable and open in the browser.

If the other person is offline, the message waits for them on the node for up to 72 hours and is delivered as soon as they connect.

## What the icons mean

| Icon | Meaning |
|---|---|
| progress bar | the message or file is still being sent |
| 🕓 orange clock | the other person is offline — the message is waiting for them on the node |
| ✓ one check mark | delivered to the other person's phone |
| ✓✓ two check marks | read |
| ⓘ red icon | not sent |

If a message wasn't sent, the line "Message not sent. Send again?" appears under it — tap it when the connection is back.

## Photos, videos and files

Tap **⊕** to the left of the input field:

- **Photo or video** — from your phone's photo library;
- **File** — any document from the iPhone Files app: PDFs, spreadsheets, archives and so on.

What happens before sending:

- **photos** are scaled down to 1280 pixels on the long side — so they go out fast and don't take up space on the other person's phone;
- **videos** from the library are compressed to 720p MP4. If the clip is still larger than 50 MB, the app tries a lower quality;
- **files** are sent as they are.

The largest single attachment is **50 MB**. The app won't send a larger file and will tell you so. A video sent as a "File" is not compressed — for long clips choose "Photo or video".

A large file is sent in parts, and you can see the progress under the message. If the connection drops or the app is closed, sending resumes by itself after reconnecting — from where it stopped, not from the beginning. **During a call, file transfer is paused** so the call isn't disturbed, and it resumes after the call.

Messages in a chat arrive in the order you sent them: a caption or voice comment sent after a photo or video arrives after it.

> While a large file is being sent, don't close Nevod or leave the phone locked for long: iOS stops an app in the background after a while, and sending will continue only when you open Nevod again.

To **open** a received photo, video or file, tap it. To **save** it or forward it — long-press → **Share**.

The app checks received photos and videos first: if a file only claims to be a picture or video but actually isn't one, it is shown as a plain file and not opened as an image. Open files from strangers with care — as in any messenger.

## Voice messages

Tap the microphone icon to the right of the input field — recording starts, with a timer next to it. Tap **✓** to send or **✕** to cancel. The microphone works when the app is connected to the node.

When Nevod asks for microphone access for the first time, allow it — recording is impossible without it.

## What you can do with a message

Touch and hold a message — a menu appears:

| Action | What it does |
|---|---|
| **Reply** | reply quoting this message |
| **Copy** | copy the message text — for text messages |
| **Share** | copy the text, save a photo or file, forward it through another app |
| **Edit** | correct the text of your message — it changes for the other person too |
| **Delete for me** | delete the message only on your phone |
| **Delete for everyone** | delete your message for both you and the other person |
| **Report** | for someone else's message — send a report to the administration |

"Edit" is available only for your own text messages, "Delete for everyone" only for your own messages, "Report" only for other people's.

> "Delete for everyone" deletes the message in the other person's app. But if they have already read it, saved the photo or taken a screenshot, deleting won't undo that.

To stop seeing “Message deleted” in place of messages deleted for everyone, turn off **Profile → Chats → Show “Message deleted”**.

## Message notifications

When Nevod is closed, a new message brings a "New message" notification with the sender's name — as it is saved in your contacts. The notification contains no message text: it is encrypted, and neither the node nor Apple can see it.

To turn off notifications for one chat: chat settings (the gear at the top right) → **Notifications**.

## Church Slavonic text

Nevod has a built-in Church Slavonic keyboard and font. The keyboard is turned on in the iPhone settings — **Profile → Church Slavonic keyboard** explains how. When you switch to it, the app turns on the matching font by itself; you can turn it on manually in the **⊕ → Church Slavonic font** menu.
