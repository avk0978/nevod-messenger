# Messages et fichiers

Comment écrire, envoyer des photos, des vidéos, des messages vocaux et des fichiers, ce que signifient les icônes à côté d'un message et ce que vous pouvez faire d'un message déjà envoyé.

Tout ce que vous envoyez est chiffré sur votre téléphone avec la clé du destinataire. Les nœuds acheminent les messages, mais ne peuvent pas les lire.

## Texte

Écrivez votre message dans le champ **Message** en bas de la discussion et touchez la flèche bleue. Les liens dans les messages sont cliquables et s'ouvrent dans le navigateur.

Si votre interlocuteur n'est pas connecté, le message l'attend sur le nœud jusqu'à 72 heures et lui est remis dès qu'il se connecte.

## Ce que signifient les icônes

| Icône | Signification |
|---|---|
| barre de progression | le message ou le fichier est encore en cours d'envoi |
| 🕓 horloge orange | votre interlocuteur n'est pas connecté : le message l'attend sur le nœud |
| ✓ une coche | remis sur le téléphone de votre interlocuteur |
| ✓✓ deux coches | lu |
| ⓘ icône rouge | non envoyé |

Si un message n'est pas parti, la ligne « Message non envoyé. Renvoyer ? » apparaît en dessous : touchez-la quand la connexion revient.

## Photos, vidéos et fichiers

Touchez **⊕** à gauche du champ de saisie :

- **Photo ou vidéo** : depuis la photothèque du téléphone ;
- **Fichier** : n'importe quel document de l'app Fichiers de l'iPhone : PDF, tableurs, archives, etc.

Ce qui se passe avant l'envoi :

- les **photos** sont réduites à 1280 pixels sur le grand côté : elles partent vite et ne prennent pas de place chez votre interlocuteur ;
- les **vidéos** de la photothèque sont compressées en MP4 720p. Si le clip dépasse encore 50 Mo, l'app essaie une qualité plus faible ;
- les **fichiers** sont envoyés tels quels.

La taille maximale d'une pièce jointe est de **50 Mo**. L'app n'envoie pas un fichier plus gros et vous le signale. Une vidéo envoyée comme « Fichier » n'est pas compressée : pour les longues vidéos, choisissez « Photo ou vidéo ».

Un gros fichier est envoyé par morceaux, et vous voyez la progression sous le message. Si la connexion est coupée ou si l'app se ferme, l'envoi reprend tout seul après la reconnexion, là où il s'était arrêté et non depuis le début. **Pendant un appel, le transfert de fichiers est suspendu** pour ne pas gêner l'appel, puis il reprend.

Les messages d'une discussion arrivent dans l'ordre où vous les avez envoyés : une légende ou un commentaire vocal envoyé après une photo ou une vidéo arrive après elle.

> Pendant l'envoi d'un gros fichier, ne fermez pas Nevod et ne laissez pas le téléphone verrouillé longtemps : iOS arrête au bout d'un moment une app en arrière-plan, et l'envoi ne reprendra que lorsque vous rouvrirez Nevod.

Pour **ouvrir** une photo, une vidéo ou un fichier reçu, touchez-le. Pour l'**enregistrer** ou le transférer : appui prolongé → **Partager**.

L'app vérifie d'abord les photos et vidéos reçues : si un fichier prétend seulement être une image ou une vidéo sans en être une, il est affiché comme un simple fichier et ne s'ouvre pas comme une image. Ouvrez les fichiers d'inconnus avec prudence, comme dans toute messagerie.

## Messages vocaux

Touchez l'icône du micro à droite du champ de saisie : l'enregistrement démarre, avec un minuteur à côté. Touchez **✓** pour envoyer ou **✕** pour annuler. Le micro fonctionne quand l'app est connectée au nœud.

Quand Nevod demande l'accès au micro pour la première fois, acceptez : sans lui, aucun enregistrement n'est possible.

## Ce que vous pouvez faire d'un message

Maintenez le doigt sur un message : un menu apparaît.

| Action | Ce qu'elle fait |
|---|---|
| **Répondre** | répondre en citant ce message |
| **Copier** | copier le texte du message — pour les messages texte |
| **Partager** | copier le texte, enregistrer la photo ou le fichier, le transférer via une autre app |
| **Modifier** | corriger le texte de votre message ; il change aussi chez votre interlocuteur |
| **Supprimer pour moi** | supprimer le message seulement sur votre téléphone |
| **Supprimer pour tous** | supprimer votre message chez vous et chez votre interlocuteur |
| **Signaler** | pour le message d'un autre : envoyer un signalement à l'administration |

« Modifier » n'existe que pour vos propres messages texte, « Supprimer pour tous » que pour vos propres messages, « Signaler » que pour ceux des autres.

> « Supprimer pour tous » efface le message dans l'app de votre interlocuteur. Mais s'il l'a déjà lu, a enregistré la photo ou fait une capture d'écran, la suppression n'y change rien.

Pour ne plus voir « Message supprimé » à la place des messages supprimés pour tous, désactivez **Profil → Discussions → Afficher « Message supprimé »**.

## Notifications de messages

Quand Nevod est fermé, un nouveau message déclenche la notification « Nouveau message » avec le nom de l'expéditeur, tel qu'il est enregistré dans vos contacts. La notification ne contient pas le texte du message : il est chiffré, et ni le nœud ni Apple ne peuvent le voir.

Pour couper les notifications d'une seule discussion : réglages de la discussion (la roue dentée en haut à droite) → **Notifications**.

## Texte en slavon d'église

Nevod intègre un clavier et une police de slavon d'église. Le clavier s'active dans les réglages de l'iPhone ; **Profil → Clavier slavon d'église** explique comment. Quand vous passez à ce clavier, l'app active d'elle-même la police adaptée ; pour l'activer à la main, utilisez le menu **⊕ → Police slavon d'église**.
