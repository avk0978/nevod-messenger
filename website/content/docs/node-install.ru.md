# Установка шаг за шагом

Как поставить узел Nevod на арендованный сервер с нуля: от покупки сервера до первого входа в панель администратора. Пример — сервер с Ubuntu 24.04 и домен `node.example.org`; вместо него везде подставляйте свой.

Все команды ниже вводятся в терминале сервера, их можно копировать целиком. Что такое узел и что он хранит — в разделе [Как устроен узел](../node-how/).

## 1. Арендуйте сервер

Подойдёт любой VPS у любого провайдера: 1 процессор, 1 ГБ памяти, 10 ГБ диска, система **Ubuntu 24.04**. При заказе провайдер выдаст **IP-адрес** сервера и пароль пользователя `root` (или попросит загрузить SSH-ключ).

Если у провайдера есть свой сетевой файрвол в панели управления (например, Firewalls у Hetzner, Security groups у других), откройте в нём входящие порты **22, 80, 443 и 8765** (TCP).

## 2. Направьте домен на сервер

В панели управления вашим доменом создайте **A-запись**: имя — например `node` (получится `node.example.org`), значение — IP-адрес сервера.

Подождите несколько минут и проверьте с любого компьютера:

```
ping node.example.org
```

В ответе должен быть IP-адрес вашего сервера. Пока этого нет, дальше идти бессмысленно: сертификат HTTPS выдаётся только домену, который уже указывает на сервер.

> Если домен обслуживает Cloudflare, отключите для этой записи проксирование (серое облако, «DNS only»). Иначе телефоны и другие узлы будут подключаться к Cloudflare, а не к вашему серверу.

## 3. Подключитесь к серверу

На своём компьютере откройте терминал (на Windows — PowerShell, на Mac — «Терминал») и введите:

```
ssh root@node.example.org
```

При первом подключении ответьте `yes` и введите пароль от провайдера.

## 4. Установите Docker и git

```
apt update && apt upgrade -y
apt install -y git
curl -fsSL https://get.docker.com | sh
```

Последняя команда — официальный установщик Docker. Проверьте, что всё на месте:

```
docker compose version
```

Должна появиться строка вида `Docker Compose version v2…`.

## 5. Включите файрвол

```
ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 8765/tcp
ufw enable
```

На вопрос ответьте `y`. Порты 80 и 443 нужны для HTTPS (телефоны и панель), 8765 — для связи с другими узлами.

> Docker открывает порты своих контейнеров сам, в обход `ufw`. Поэтому в нашем комплекте панель администратора (порт 8766) опубликована только для самого сервера — не меняйте это в `docker-compose.yml`.

## 6. Скачайте Nevod

```
git clone https://github.com/avk0978/nevod-messenger.git /opt/nevod
cd /opt/nevod/installer/docker
```

## 7. Заполните настройки

Создайте файл настроек из образца:

```
cp .env.example .env
```

Придумайте пароль для панели администратора. Удобнее всего сгенерировать длинный случайный:

```
openssl rand -base64 24
```

Скопируйте результат и сохраните его в менеджере паролей. Теперь откройте файл настроек:

```
nano .env
```

Измените две строки:

```
NEVOD_DOMAIN=node.example.org
NEVOD_ADMIN_PASSWORD=сюда-сгенерированный-пароль
```

Остальное оставьте как есть. Сохраните файл: **Ctrl+O**, затем **Enter**, выход — **Ctrl+X**.

| Настройка | Что значит |
|---|---|
| `NEVOD_DOMAIN` | Домен узла. Телефоны подключаются к `https://домен/nevod-ws`, другие узлы — к `домен:8765`. |
| `NEVOD_ADMIN_PASSWORD` | Пароль панели администратора. Без него узел не запустится. |
| `NEVOD_ADMIN_PUBLIC` | `true` — панель открывается в браузере по адресу `https://домен/nevod-admin`; `false` — панель закрыта для интернета (см. шаг 10). |
| `TURN_SECRET` | Только если вы ставите свой ретранслятор звонков, см. [Звонки через свой узел](../node-turn/). Обычно пусто. |

## 8. Запустите узел

```
docker compose up -d --build
```

Первый запуск занимает несколько минут: Docker собирает образ узла и скачивает Caddy. Когда команда закончится, проверьте:

```
docker compose ps
```

Оба контейнера — `nevod_node` и `nevod_caddy` — должны быть в состоянии `Up` (или `running`).

## 9. Проверьте, что всё работает

Откройте в браузере `https://node.example.org` — должна появиться строка «Nevod node — https://nevod.network», а браузер не должен ругаться на сертификат.

Теперь откройте `https://node.example.org/nevod-admin`. Браузер спросит логин и пароль: логин — любой, пароль — тот, что вы вписали в `.env`. Откроется панель администратора. Что в ней сделать в первую очередь — в разделе [Первая настройка в панели администратора](../node-panel/).

> Пять неверных паролей подряд с одного адреса закрывают вход в панель для этого адреса на 15 минут. Если это случилось — просто подождите.

## 10. По желанию: закройте панель от интернета

Если вы не хотите, чтобы адрес панели вообще открывался из интернета, впишите в `.env` строку `NEVOD_ADMIN_PUBLIC=false` и примените:

```
docker compose up -d
```

Тогда панель доступна только через SSH-туннель. На своём компьютере выполните

```
ssh -L 8766:127.0.0.1:8766 root@node.example.org
```

и, пока это окно открыто, откройте в браузере `http://localhost:8766/nevod-admin`.

## Если что-то не так

| Что видите | В чём обычно дело |
|---|---|
| Браузер пишет, что сертификат недействителен, или сайт не открывается | Домен ещё не указывает на сервер (шаг 2) или закрыт порт 80/443 (шаги 1 и 5). Посмотрите журнал Caddy: `docker compose logs caddy`. Когда причина устранена, Caddy сам повторит попытку. |
| `docker compose up` пишет `address already in use` | На сервере уже работает другой веб-сервер (часто Apache или nginx от провайдера). Остановите его: `systemctl disable --now apache2` или `systemctl disable --now nginx`. |
| Ошибка `set NEVOD_ADMIN_PASSWORD in .env` или `set NEVOD_DOMAIN in .env` | Не заполнена эта строка в `.env` (шаг 7). |
| Панель снова и снова спрашивает пароль | Неверный пароль. Посмотреть, какой записан: `grep PASSWORD .env`. |
| Панель отвечает «Too many failed logins» | Сработала защита от подбора пароля — подождите 15 минут. |
| `nevod_node` всё время перезапускается | Журнал узла покажет причину: `docker compose logs --tail 50 nevod_node`. |

Журналы обоих контейнеров целиком: `docker compose logs`. Все команды `docker compose` выполняются из папки `/opt/nevod/installer/docker`.
