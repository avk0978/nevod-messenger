# Первая настройка в панели администратора

Узел запущен — теперь его нужно назвать, решить, кого на него пускать, и зарегистрироваться на нём самому. Всё это делается в панели администратора по адресу `https://node.example.org/nevod-admin` (как её открыть — в шаге 9 [установки](../node-install/)).

Язык панели переключается в её шапке. Подробное описание каждой страницы и настройки — в разделе [Панель администратора: все страницы и настройки](../node-admin/).

## Что в панели где

| Страница | Для чего |
|---|---|
| **Обзор** | Зарегистрированные на узле ячейки (пользователи). |
| **Настройки** | Имя узла, режим допуска, видимость. |
| **Заявки на подключение** | Заявки пользователей, если узел работает в режиме одобрения. |
| **Обращения** | Сообщения пользователей администратору узла — жалобы, вопросы. Отвечать можно прямо отсюда. |
| **Приглашения** | Коды приглашений для пользователей. |
| **Узлы** | Подключение к общей сети Nevod и другие узлы, которые знает ваш узел. |
| **Публикация**, **AI-боты** | Боты и каналы, которые узел показывает своим пользователям. |
| **Безопасность** | Дополнительные учётные записи администраторов. |
| **Диагностика** | Самопроверка узла и его журнал. |

## 1. Назовите узел

**Настройки → Имя ноды** → впишите название, например «Семья Ивановых» или «Школа №5», → **Сохранить**.

Название видят пользователи в приложении. Другие узлы сети узнают новое имя после перезапуска узла (см. ниже). Нельзя использовать имена, которые выдают узел за узел проекта: со словами Nevod, admin, support, official и т. п.

## 2. Решите, кого пускать

**Настройки → Режим допуска ячеек.** Новый узел по умолчанию работает **по приглашению**: зарегистрироваться можно только с кодом, который вы выдали. Обычно это и нужно. В приложении, в **Обзоре сети**, узел в режимах по приглашению и с одобрения отмечен замком 🔒 — так люди заранее видят, что просто так зарегистрироваться нельзя.

| Режим в панели | Кто может зарегистрироваться | Кто создаёт коды приглашения |
|---|---|---|
| `delegated` — только по коду приглашения (по умолчанию) | Только с кодом приглашения. Без кода узел регистрацию не принимает. | Вы в панели, а также пользователи, которым вы дали право **Может приглашать**. |
| `admin` — заявка + ваше одобрение | С кодом — сразу. Без кода приложение само отправляет заявку и показывает «Ожидание одобрения»; вы одобряете или отклоняете её на странице **Заявки на подключение**. | Только вы, в панели. |
| `open` — без кода | Любой, кто знает адрес узла. Подходит для открытого сообщества; учтите, что регистрации и занятые имена потом придётся разбирать вручную. | Код не нужен. |

Режим применяется сразу.

## 3. Зарегистрируйтесь на своём узле

1. В панели: **Приглашения** → выберите срок действия (1 час, 24 часа или 7 дней) → **+ Создать код**. Появятся QR-код и короткий код вида `ABCD-EFGH`.
2. На телефоне установите Nevod из App Store.
3. Отсканируйте QR-код обычной камерой телефона. Это ссылка: откроется страница приглашения — нажмите на ней **Открыть в Nevod**. Приложение откроется с уже заполненными адресом вашего узла и кодом.
4. Впишите своё имя и нажмите **Начать**.

Если сканировать неудобно — нажмите в панели **Скопировать ссылку** и отправьте её себе. Если кнопка «Открыть в Nevod» не сработала: в приложении нажмите **Начать переписку**, впишите имя, нажмите **Есть код приглашения?** и вставьте ссылку в поле кода. Короткий код вместо ссылки подходит, только когда в приложении уже указан ваш узел.

> Если Nevod на этом телефоне уже зарегистрирован на другом узле (например, на Nevod Open), приглашение само не переведёт вас на свой узел — приложение предупредит, что сначала нужно сбросить личность: **Профиль → Сбросить личность…**. Сброс навсегда удаляет личность, контакты, переписку на телефоне и регистрацию на прежнем узле. После сброса откройте ссылку приглашения ещё раз.

Каждый код одноразовый. Для каждого человека создавайте свой — подробнее в разделе [Как позвать людей](../node-invite/).

## 4. Решите, виден ли узел в сети

**Настройки → Видимость в «Обзоре сети»**:

- `closed` (по умолчанию) — узел не показывается в «Обзоре сети» у пользователей других узлов. Подходит для семьи, организации, любой закрытой группы.
- `open` — узел появляется в «Обзоре сети», и пользователи других узлов могут его найти. Подходит для открытого сообщества. Узел виден, пока он на связи с сетью, и только тем, кто уже зарегистрирован на каком-либо узле: до регистрации приложение показывает лишь узлы проекта.

Этот выбор не открывает регистрацию: кого пускать, по-прежнему решает режим допуска ячеек (шаг 2). Золотое кольцо проверенного узла в «Обзоре сети» сейчас бывает только у узлов проекта Nevod.

Эта настройка, как и имя узла для других узлов, применяется после перезапуска узла. На сервере, в папке `/opt/nevod/installer/docker`:

```
docker compose restart nevod_node
```

## 5. Проверьте узел

**Диагностика → Проверить.** Через несколько секунд узел покажет, всё ли в порядке: актуален ли код, совпадают ли его настройки и база данных, нет ли проблем с конфигурацией, доступен ли узел снаружи.

Доступность снаружи узел проверяет через другие узлы сети. Пока ваш узел ни к кому не подключён, эта строка покажет «Нет известных пиров» — это ожидаемо. Подключение к сети — следующий шаг, и он важен: без него телефоны не будут получать уведомления, пока приложение закрыто. См. [Подключение к общей сети Nevod](../node-network/).

## 6. По желанию: ещё администраторы

**Безопасность → Добавить / сменить пароль** — у каждого администратора будет свой логин и пароль, и вход по ним можно отозвать, не меняя главный пароль из `.env`. Главный пароль остаётся запасным входом на случай, если остальные потеряны.
