# Premiers pas

Comment installer Nevod, vous inscrire et écrire votre premier message. Cela prend quelques minutes, sans numéro de téléphone ni adresse e-mail.

## Ce qu'il vous faut

Un iPhone ou un iPad sous iOS 17.2 ou plus récent. L'app s'appelle **Nevod** et se trouve sur l'App Store. Une version Android est en développement.

## Cellule et nœud en deux mots

- Une **cellule**, c'est vous dans Nevod : une paire de clés de chiffrement que l'app crée sur votre téléphone. Les clés ne quittent jamais l'appareil, si bien que personne d'autre que vous et votre interlocuteur ne peut lire vos messages.
- Un **nœud** est un serveur que l'app utilise pour acheminer les messages. Une cellule s'inscrit sur un nœud : son **nœud d'attache**. Il existe des nœuds publics, comme **Nevod Open**, et des nœuds privés : d'une famille, d'une organisation, d'une communauté. Un nœud voit à qui vous écrivez et quand, mais pas ce que vous écrivez.

Vous pouvez écrire aux personnes de n'importe quel nœud du réseau, pas seulement du vôtre.

## Inscription

1. Ouvrez Nevod. L'app demande l'autorisation d'envoyer des notifications : acceptez, sinon vous ne saurez rien des messages et des appels tant que Nevod est fermé.
2. Lisez l'essentiel des Conditions d'utilisation, activez **J'accepte les Conditions d'utilisation** et touchez **Continuer**.
3. **Explorer le réseau** s'ouvre : une liste de nœuds ouverts. Vous pouvez y jeter un œil : les nœuds, leurs bots et leurs pages sont accessibles sans inscription. Tant que vous n'êtes inscrit sur aucun nœud, la liste ne montre que les nœuds du projet Nevod ; les autres nœuds ouverts du réseau apparaissent après l'inscription, car l'app reçoit leur liste de votre nœud.
4. Touchez **Commencer à discuter** (en haut à droite).
5. Saisissez **Votre nom affiché** : c'est ainsi que les autres vous verront. Touchez **Commencer**.

C'est fait : vous êtes inscrit sur le nœud **Nevod Open**. Dans quelques secondes, vous recevrez un message de bienvenue de **administrator**, le compte de l'administration du nœud. Un badge bleu ✓ figure à côté de son nom.

> Le nom doit être libre sur ce nœud. Si l'app indique que le nom est déjà pris, choisissez-en un autre. Des noms comme administrator, admin, support ou Nevod ne peuvent pas être pris : ainsi, personne ne peut se faire passer pour l'administration. Vous pourrez changer de nom plus tard dans le **Profil**.

> **Les comptes de service sont signalés.** Chaque nœud a son propre compte **administrator**. Sur les nœuds du projet Nevod, comme Nevod Open, il porte un badge bleu ✓ : c'est l'administration de Nevod, et le badge est confirmé par la signature du projet. Sur un nœud privé — d'une famille, d'une organisation, d'une communauté —, administrator porte la mention **Administrateur du nœud** avec le nom du nœud, confirmée par la clé de ce nœud lui-même. Ni le badge ni la mention ne peuvent être falsifiés. Si un nom ressemble à un nom de service — administrator, admin, support, Nevod, « Administrateur du réseau », etc. — mais n'a ni le badge ✓ ni la mention, un ⚠ orange apparaît à côté du nom et la discussion affiche l'avertissement « Ce n'est pas un compte officiel Nevod ». Ne donnez à cette personne ni mot de passe, ni clé, ni code.

## Si vous avez été invité sur un nœud

Si vous avez reçu un lien ou un code QR d'invitation — par exemple pour le nœud de votre famille ou de votre organisation :

1. Installez Nevod et acceptez les Conditions (étape 1 ci-dessus).
2. Ouvrez le lien ou scannez le code QR avec l'appareil photo du téléphone. Sur la page d'invitation, touchez **Ouvrir dans Nevod**.
3. L'app s'ouvre avec l'adresse du nœud et le code déjà remplis : saisissez votre nom et touchez **Commencer**.

Si « Ouvrir dans Nevod » n'a pas fonctionné : dans l'app, touchez **Commencer à discuter**, saisissez votre nom, touchez **Vous avez un code d'invitation ?** et collez le lien dans le champ du code (ou scannez le code QR avec l'icône à côté du champ).

Un code d'invitation ne sert qu'une fois et pour une durée limitée. Si l'app indique « Code invalide ou expiré — demandez-en un nouveau », demandez une nouvelle invitation.

Si Nevod est déjà inscrit sur un autre nœud sur ce téléphone, l'invitation ne vous y transfère pas d'elle-même : une identité a un seul nœud d'attache. Que faire : voir [Contacts](../contacts/), « Personnes d'autres nœuds ».

Certains nœuds admettent sur demande : l'app affiche alors **En attente d'approbation** ; l'administrateur du nœud examinera votre demande et vous recevrez une notification.

## Où trouver quoi dans l'app

| Onglet | Ce qu'il contient |
|---|---|
| **Discussions** | Vos conversations. |
| **Appels** | L'historique des appels. |
| **Contacts** | Vos interlocuteurs ; c'est aussi là que se trouve **Ajouter un contact**. |
| **Nœuds** | Explorer le réseau : les nœuds, leurs bots et leurs pages. |
| **Profil** | Votre nom et votre avatar, votre carte pour échanger vos coordonnées, les invitations, la sécurité. |

## Votre premier message

Pour écrire à quelqu'un, échangez vos contacts :

1. L'un de vous : **Profil → Partager ma carte** ; un code QR apparaît.
2. L'autre : **Contacts → Ajouter un contact**, puis scanne le code QR (ou colle le texte de la carte s'il l'a reçue).
3. Ouvrez le contact et écrivez un message.

Plus de détails dans [Contacts](../contacts/).
