Erste Schritte

Wie du Nevod installierst, dich registrierst und deine erste Nachricht schreibst. Das dauert ein paar Minuten, und du brauchst weder eine Telefonnummer noch eine E-Mail-Adresse.

Was du brauchst

Ein iPhone oder iPad mit iOS 17.2 oder neuer. Die App heißt Nevod und ist im App Store. Eine Android-Version ist in Entwicklung.

Zelle und Node in zwei Sätzen

  • Eine Zelle bist du in Nevod: ein Paar Verschlüsselungsschlüssel, das die App auf deinem Telefon erzeugt. Die Schlüssel verlassen das Gerät nie, deshalb kann niemand außer dir und deinem Gesprächspartner deine Nachrichten lesen.
  • Ein Node ist ein Server, über den die App Nachrichten zustellt. Eine Zelle registriert sich auf einem Node — ihrem Heim-Node. Es gibt öffentliche Nodes wie Nevod Open und private — für eine Familie, eine Organisation, eine Community. Ein Node sieht, wem und wann du schreibst, aber nicht, was.

Du kannst mit Menschen auf allen Nodes des Netzes schreiben, nicht nur auf deinem eigenen.

Registrierung

  1. Öffne Nevod. Die App fragt nach der Erlaubnis für Mitteilungen — erlaube sie, sonst erfährst du nichts von Nachrichten und Anrufen, solange Nevod geschlossen ist.
  2. Lies das Wichtigste aus den Nutzungsbedingungen, schalte Ich akzeptiere die Nutzungsbedingungen ein und tippe auf Weiter.
  3. Netzwerk erkunden öffnet sich — eine Liste offener Nodes. Beim ersten Start zeigt die App eine kurze Anleitung: was ein Node ist, wie du dich registrierst und wie man Karten austauscht; mit der Taste ? oben links öffnest du sie wieder. Hier kannst du dich umsehen: Nodes und ihre Seiten sind auch ohne Registrierung zugänglich. Geschlossene Nodes sind mit einem Schloss 🔒 markiert — ihnen trittst du auf Einladung oder mit Zustimmung des Administrators bei. Solange du auf keinem Node registriert bist, stehen in der Liste nur die Nodes des Nevod-Projekts; die übrigen offenen Nodes des Netzes erscheinen nach der Registrierung — ihre Liste bekommt die App von deinem Node.
  4. Tippe auf Chatten beginnen (oben rechts).
  5. Gib Dein Anzeigename ein — so sehen dich andere. Tippe auf Los geht's.

Tippst du vor der Registrierung auf einer Node-Seite auf einen Bot, fragt die App nach einem Namen oder Spitznamen und registriert dich auf diesem Node — ohne Namen ist keine Registrierung möglich. Ist der Node geschlossen, fragt die App zuerst, ob eine Anfrage an den Administrator gesendet werden soll.

Fertig: Du bist auf dem Node Nevod Open registriert. In wenigen Sekunden kommt eine Begrüßungsnachricht von administrator, dem Konto der Node-Administration. Neben seinem Namen steht ein blaues ✓-Abzeichen.

Der Name muss auf diesem Node frei sein. Wenn die App meldet, dass der Name vergeben ist, wähle einen anderen. Namen wie administrator, admin, support, Nevod können nicht vergeben werden — so kann sich niemand als Administration ausgeben. Den Namen kannst du später im Profil ändern.

Dienstkonten sind gekennzeichnet. Jeder Node hat sein eigenes Konto administrator. Auf den Nodes des Nevod-Projekts, etwa auf Nevod Open, trägt es ein blaues ✓-Abzeichen — das ist die Nevod-Administration, das Abzeichen wird durch die Signatur des Projekts bestätigt. Auf einem privaten Node — einer Familie, einer Organisation, einer Community — ist administrator mit Node-Administrator und dem Namen des Nodes gekennzeichnet; das bestätigt der Schlüssel dieses Nodes selbst. Weder das Abzeichen noch die Kennzeichnung lassen sich fälschen. Sieht ein Name wie ein Dienstname aus — administrator, admin, support, Nevod, „Netzwerk-Administrator“ und Ähnliches —, hat aber weder das ✓-Abzeichen noch die Kennzeichnung, steht neben dem Namen ein oranges ⚠ und im Chat die Warnung „Dies ist kein offizielles Nevod-Konto“. Gib so jemandem keine Passwörter, Schlüssel oder Codes.

Wenn du auf einen Node eingeladen wurdest

Wenn du einen Einladungslink oder QR-Code bekommen hast — zum Beispiel für den Node deiner Familie oder Organisation:

  1. Installiere Nevod und akzeptiere die Bedingungen (Schritt 1 oben).
  2. Öffne den Link oder scanne den QR-Code mit der Kamera deines Telefons. Tippe auf der Einladungsseite auf In Nevod öffnen.
  3. Die App öffnet sich mit bereits ausgefüllter Node-Adresse und Code — gib deinen Namen ein und tippe auf Los geht's.

Falls „In Nevod öffnen“ nicht funktioniert hat: Tippe in der App auf Chatten beginnen, gib deinen Namen ein, tippe auf Hast du einen Einladungscode? und füge den Link in das Code-Feld ein (oder scanne den QR-Code mit dem Symbol neben dem Feld).

Ein Einladungscode gilt einmal und nur für begrenzte Zeit. Meldet die App „Ungültiger oder abgelaufener Code — hol dir einen neuen“, bitte um eine neue Einladung.

Ist Nevod auf diesem Telefon schon auf einem anderen Node registriert, verschiebt dich die Einladung nicht von selbst: Eine Identität hat einen Heim-Node. Was zu tun ist — siehe Kontakte, „Menschen auf anderen Nodes“. Ist die Einladung für deinen eigenen Node, zeigt die App „Du bist auf diesem Node bereits registriert“ — es ist nichts zu tun.

Manche Nodes nehmen auf Antrag auf: Dann zeigt die App Warten auf Freigabe — der Administrator des Nodes prüft deinen Antrag, und du bekommst eine Mitteilung.

Deine erste Nachricht

Um jemandem zu schreiben, tauscht ihr Kontakte aus:

  1. Einer von euch: Profil → Meine Karte teilen — ein QR-Code erscheint.
  2. Der andere: Kontakte → Kontakt hinzufügen — und scannt den QR-Code (oder fügt den Kartentext ein, wenn er geschickt wurde).
  3. Öffne den Kontakt und schreib eine Nachricht.

Mehr unter Kontakte.

Wie es weitergeht

  • Kontakte — Karten, Einladungen, Menschen auf anderen Nodes.
  • Nachrichten und Dateien — Fotos, Videos, Sprachnachrichten, für alle löschen.
  • Sicherheit und Backups — was tun, wenn du das Telefon wechselst oder verlierst.
