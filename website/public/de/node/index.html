Einen eigenen Nevod-Node betreiben

Ein Node ist ein kleiner Server, über den Telefone Nachrichten und Anrufe austauschen. Er sieht nur verschlüsselte Daten. Eine Organisation, Gemeinschaft, Schule oder Familie kann ihren eigenen betreiben — genau deshalb hat das Netz keinen zentralen, vom Entwickler kontrollierten Punkt.

Was du brauchst

  • Einen Computer oder Server mit Linux oder Windows und installiertem Docker
  • Mindestens 1 GB Arbeitsspeicher
  • Für Zugriff aus dem Internet eine öffentliche Adresse oder Domain; für ein Stadtnetz oder WLAN genügt eine lokale Adresse

So funktioniert es

  1. Der Node läuft in Docker und hat ein Web-Adminpanel.
  2. Im Panel legst du den Namen des Nodes und den Zulassungsmodus fest (offen, per Einladung oder mit Freigabe durch den Administrator) und verbindest den Node auf Wunsch mit dem Nevod-Netz.
  3. Telefone verbinden sich über die Adresse des Nodes oder einen Einladungs-QR-Code.

Die Node-Software ist Open Source: github.com/avk0978/nevod-messenger (GNU AGPL-3.0). Die Dateien zum Betrieb eines Nodes in Docker liegen im Ordner installer/docker des Repositorys. Auch die Einrichtung eines Nodes mithilfe eines KI-Assistenten ist in Entwicklung.
